# Block Builder Drums (Sixteenth Flow Blocks)

Drums-only hands/feet coordination practice app. R / L / K stickings, subdivisions (1/4 to septuplets), meters (2/4 to 9/8), accents, routines, checklist, saved phrases, synthesized sounds, metronome with count-in and spoken count.

## Live app
https://fraz97-design.github.io/block-builder-drums/

On iPad/iPhone: open the link in Safari, tap Share, then "Add to Home Screen".

## Source
- GitHub repo: https://github.com/fraz97-design/block-builder-drums
- Original Claude artifact: https://claude.ai/artifact/Sn3rXPWHr7acA7Go8A3Aw9

## Files
- `index.html`: the whole app in one file (HTML, CSS, JS, voice samples). No build step, no internet calls.

## Update it
1. Get the new `index.html`.
2. In the repo, Add file > Upload files, drop it in, Commit.
3. Pages redeploys in about a minute.

Saved data (checklist, saved phrases, settings) lives in each browser's local storage, so it stays per device.
